# 记事喵 · TaskCat

**你的 AI 待办管家。一句话，安排好每件事。**

记事喵是一个原生 macOS 菜单栏应用。用自然语言新增任务、调整日期、管理分组和标记完成，也能直接手动编辑。支持自己配置云端或本地模型，微信是可选的便捷入口。

[介绍站点](https://tab16360.github.io/taskcat/) · [下载预览版](https://github.com/tab16360/taskcat/releases/tag/v0.2.8-preview.1) · [使用指南](GUIDE.md) · [隐私与安全](SECURITY.md)

当前是**早期预览版**，不承诺生产级稳定性。macOS 14+；Apple Silicon 已在开发机实测，Intel 与其他系统版本尚未验收。尚无独立 iOS App。

## 能做什么

| 场景 | 能力 |
| --- | --- |
| 一句话安排 | 新增、查询、编辑、改期、完成、删除；修改前校验，危险操作确认 |
| 菜单栏管理 | 查看待办、状态筛选、分组切换、手动编辑；收起对话后保持窗口高度 |
| 分组与进度 | 创建、改名和删除分组，任务进度按10%档记录，100%时询问是否完成 |
| 模型自由选 | 多套 OpenAI 兼容接口或本地 Ollama 配置，界面与微信都可切换 |
| 到期提醒 | 显式写入系统提醒事项闹钟；Bark 作为额外可选通道 |
| 回收与备份 | 删除前保存本机快照，移除系统对应提醒；按原编号恢复、备份导出/合并恢复 |
| 微信入口 | 可选桥接，共用任务服务与稳定编号；核心应用无需 Python |

示例：“明天下午三点提醒我交方案”“任务5标记完成”“项目A分组改名项目B”。模型可能理解错误，执行前请核对确认内容。

## 任务存在哪里

记事喵是独立产品，底层复用系统提醒事项的基础任务存储、iCloud 同步和通知。选择 iCloud 账户后，基础任务可在 iPhone 系统提醒事项中查看、修改和接收通知。已同步的系统通知不要求 Mac 常开。

0.2.3 起可在设置中初始化/加入 iCloud Drive 扩展同步，支持状态、进度、编号、回收快照和操作日志。两台 Mac 的首次加入及双向编辑已实测；仍是预览实现，真实并发冲突会暂停修改，不承诺生产级故障恢复或自动微信接管。换机前仍建议导出独立备份。Mac 关机后，AI、微信桥接与额外 Bark 推送不会运行。

## 安装预览版

1. 从 [Releases](https://github.com/tab16360/taskcat/releases) 下载 `TaskCat-arm64.zip`。
2. 解压，将 `记事喵.app` 放入可写的“应用程序”目录并打开。
3. 首次点击连接时允许提醒事项访问，选择提醒事项账户。
4. 设置模型服务地址、模型 ID 与自己的 Key；也可先手动管理任务。

预览包使用固定的自签名证书（0.2.9 起，此前为临时签名），未经过 Apple 公证。macOS 可能阻止首次运行；核对来源后按系统设置“隐私与安全性”的提示处理。无需关闭系统安全功能。**从临时签名版本升级到 0.2.9 时需再确认一次提醒事项访问；之后用同一证书签名的更新会保留授权。**

## 从源码构建

App源码目前未发布，以下仅用于已有本机工程；公开GitHub仓库目前只有官网与预览包。

需要 Mac、Swift 编译器及带 macOS 26+ SDK 的 Xcode/Command Line Tools（包含 Liquid Glass API；运行低版本系统时使用兼容分支）。核心应用不依赖 Python 或 Node，不需要 Apple Developer Team 即可本机编译。

```bash
cd /path/to/TaskCat
bash scripts/build-app.sh
bash scripts/install-app.sh
```

安装脚本优先更新已存在的 `/Applications/记事喵.app`，否则使用 `~/Applications/记事喵.app`，保留任务数据；老的 `TaskSecretary.app` 会备份到本机应用数据目录。构建产物保留历史 Bundle ID 与数据目录名，以维持数据与凭据兼容。

构建脚本会自动使用本机专用钥匙串 `~/Library/Keychains/taskcat-signing.keychain-db` 里的“TaskCat Local Code Signing”证书签名；该证书保持不变，macOS 在更新后会保留提醒事项授权，应用内更新也只接受同一证书签名的新版本。请备份该钥匙串及 `~/Library/Application Support/TaskCatSigning/`；证书丢失或更换后，已安装的版本无法再应用内更新，需要手动替换一次并重新授权。没有该钥匙串时回退为临时签名并给出警告。

```bash
# 仅在本机有相应正式身份时选用；不要求普通贡献者持有证书。
TASKCAT_SIGNING_IDENTITY='Developer ID Application: YOUR IDENTITY' bash scripts/build-app.sh
```

## 测试

Python 3.11+ 与 pytest 只用于测试，不是核心应用运行依赖。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q
```

当前待发布源码套件在开发机实际运行 **243 项通过**，覆盖命令校验、日期、日志一致性、备份边界、持久入站与本机 IPC 等。测试使用合成数据，不访问个人提醒事项或发送真实微信。历史开发工程中的20项早期PoC测试不包含在本仓库，不把它们计入上述结果。

开发过程中另已实测 Mac ↔ iPhone 基础任务同步、系统通知手机送达、微信收发、任务删除/恢复与备份合并；这些是有限设备上的实测，不代表所有环境已验收。为保护隐私，本仓库不公开原始任务、二维码、会话或个人测试日志。

## 可选微信接入

自己的桥接代码位于 `services/wechat-bridge/`。当前适配的第三方 SDK 为 `minibear2021/wechat_clawbot_sdk` 的固定提交 `0d1c8b4e68a22f35dd38a4c2db3ec01d39234cde`，本仓库和预览包**不包含该 SDK**。固定版本的许可信息尚未明确，需自行确认使用授权；不能将本项目协议当作第三方 SDK 的授权。

如已取得适当授权并在本地准备 SDK，可参照 [微信桥接说明](services/wechat-bridge/README.md) 配置独立运行环境。核心应用完全可在不启用微信的情况下使用。不要在两台 Mac 同时运行同一微信绑定的执行器；本版没有生产级跨机租约。

## 当前边界

- 没有独立 iOS App、完整多 Mac 扩展数据同步、自动更新或完整撤销栈。
- 含重复规则、位置或特殊提醒的任务暂拒绝可能有损的快照删除与整库备份；不承诺恢复外部创建的附件、子任务等复杂结构。
- 云模型候选最多100项，按编号/名称相关度优先；模糊自然语言仍可能匹配错误。
- 只在开发机验收了核心路径；干净机器、Intel、长期休眠/唤醒与断网场景仍需更多验证。
- 备份恢复保留现有原生任务内容。整库换机、真实冲突与强制断电恢复尚需进一步实测。
