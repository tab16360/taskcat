几件你可能想问的事。

记事喵和系统提醒事项是什么关系？＋

记事喵有自己的菜单栏界面、AI 对话、分组、状态、进度、回收站和备份。系统提醒事项承担基础任务存储、iCloud 同步和系统通知。它是底层能力，记事喵负责把日常待办管理变得顺手。

没有常开的 Mac，可以用吗？＋

可以在使用 Mac 时管理任务。已经同步到 iPhone 的任务仍可在系统提醒事项查看、编辑和接收通知。Mac 关闭后，记事喵的 AI 服务、微信机器人和额外 Bark 推送不会继续运行。

免费吗？任务会发到哪里？＋

记事喵目前提供免费预览，应用源码与许可证尚未公布，不提供内置模型额度。云模型按你选择的服务计费，本地模型需自己运行。任务交给所选系统提醒事项账户管理；扩展状态、进度、回收站和操作记录保存在 Mac 本机，可选用自己的 iCloud Drive 在两台 Mac 间同步（预览），也支持备份导出。使用云模型时会发送相关上下文。

怎么更新？为什么更新后可能再次请求授权？＋

0.2.7 起，记事喵每天检查一次 GitHub 上的新版本，发现后弹窗提醒；也可右键菜单栏图标选“检查更新…”。点“安装并重启”后会下载并校验安装包，重启时完成替换并保留旧版本备份。0.2.6 及更早版本需要手动下载这一次。当前预览版使用临时签名，替换构建后 macOS 可能重新确认提醒事项访问；同一构建重启已实测不重复申请。

有哪些还没完成？＋

没有独立 iOS App；两台 Mac 的扩展同步仍是预览实现，遇到真实冲突会暂停修改。干净机器、Intel、长期睡眠与断网场景还需更多验收。含重复规则、位置等复杂提醒暂不承诺完整删除恢复。自然语言理解可能出错，修改前请核对确认内容。
