# 后台刷新不再触发AI思考UI · 0.2.5 build 8

根因：12秒双机同步定时器调用refresh，使用busy保护读写；原输入区和标题直接按busy显示处理动画，导致未输入时也闪出“正在处理”并卸载输入框。

现改为只在busy且有processingInput的对话请求生命周期显示思考区域。同步、账户连接和手动数据操作仍保留busy保护，但不替换AI输入区。对话输入由execute设置并在defer清理，后台刷新不设置该字段。

构建、打包及严格签名检查通过。实际SwiftUI只读合成预览中，busy=true但无对话请求时，AX仍包含草稿输入框，标题为“运行中”；真正对话思考合成状态仍显示“正在思考”和活动区域。预览不调用模型或个人提醒事项，检查后已退出。没有把合成状态当作连续30秒真实同步实测。

两台已安装0.2.5。用户处理本次临时签名更新后的提醒事项访问后，两端实际App查询均为5项待办、76条日志，完整格式化输出哈希相同。未新增任务、发送Bark通知或测试微信接管。详细本地证据见 `.build/proof/silent-refresh-20261026.json` 及 `.build/silent-refresh-build.txt`。
